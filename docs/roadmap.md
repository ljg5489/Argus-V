### 01  우선순위와 현재 상태

핵심 목표는 내부 표현이 첫 권한 위반 시도 이전에 추가 정보를 제공하는지 검증하는 것이다. Guard 구축은 이를 평가하고 실행에 연결하기 위한 기반이다. 프롬프트 인젝션과 CV 확장은 보조 트랙으로 둔다.

| 진행 상태 | 2026.09.28 확인 기준 |
| --- | --- |
| 완료된 구현 검증 | C-01 Draft PR #1. 소형 GPT-2/gpt-oss 추출 테스트 67개 통과. |
| 미완료 통합 | 실제 20B·4090 실행, A/B runner 연결, 주기적 snapshot 수집, Probe와 온라인 경보. |
| 미검증 연구 | 자발적 위반의 발생 빈도, 내부 표현의 조기 신호, 외부 기준선 대비 추가 효과. |
| 일정 원칙 | 과거 M0 일정을 완료로 소급 표시하지 않는다. 10월 마지막 주 제출은 유지하고 범위를 조절한다. |

### 02  성공과 음성 결과

같은 정상 trajectory 오탐 예산에서 내부 감시를 추가한 M2가 외부·추론 감시 M1보다 일찍 또는 정확하게 탐지해야 한다. 효과가 없거나 위반 표본이 부족하면 이를 연구 결과로 보고한다. Guard 데모나 보조 공격 데이터의 성능으로 주 가설이 입증됐다고 주장하지 않는다.

| C · ljg5489 | C-01~C-05 표현·Probe·레이어/시점·OOD/실패 분석, 내부 감시 기여 보고서 |
| D | M0/M1 기준선, split/test 봉인, 공통 지표·독립 재실행, 데모·도입 조건 검토 |

### 04  C의 작업 패키지

- C-01 표현 추출: 기존 Draft PR을 실제 20B와 A/B 로그로 검증. hook·token 경계·prefix 정렬을 확정.
- C-02 Probe baseline: 고정 모델 표현과 다음 행동 위반 라벨로 Linear Probe 학습. 정책 메타데이터 누수 방지.
- C-03 레이어·시점: Single/Top-3/All과 관찰 위치 비교. 행동 생성 전/실행 전 결과 분리.
- C-04 일반화·실패: 미지 과제 계열, 정상 탐색·권한 요청의 오탐, 미탐·비용 분석.
- C-05 통합 근거: D의 M1 대비 M2 추가 기여, 선행량·불확실성·재현 코드와 PR 정리.

CV 후속: 핵심 평가가 안정된 경우만 별도 ViT 이미지 probing/OOD 실험. LLM 결과를 CV 성과로 쓰거나 OOD를 곧바로 위험으로 라벨링하지 않는다.

## 장기 Phase와 최종 점검

이번 일정은 Phase 1~2에 집중한다. 이후 단계는 실측 근거가 있을 때 진입한다.

| 단계 | 진입 조건 / 목표 |
| --- | --- |
| Phase 1 · 신호 검증 | 자발적 위반 표본과 누수 없는 pre_action Probe. 외부·추론 기준선 비교. |
| Phase 2 · 강건성·효율 | 미지 과제에서 추가 탐지 효과·오탐·수집 비용 확인. |
| Phase 3 · 실패 탐색 | 통제된 과제 변형부터 확장. 자동 red-team·RL은 필요성 확인 후 보조 실험. |
| Phase 4 · 검증된 재학습 | 독립 라벨·회귀 평가·rollback을 갖춘 Probe 개선. |
| Phase 5 · 적응 감시 | 정적 관찰 대비 레이어·관찰 주기 선택의 효과와 비용 검증. |
| Phase 6 · 제한적 개선 | 변경 범위를 제한하고 권한 정책·독립 평가·승인을 루프 외부에 유지. |

### 05  최종 제출 체크

- 자발적/유도된 사례 분리, 정상 과제·권한 경계·라벨·split 명세.
- 실제 장비 검증 상태, M0/M1/M2 및 E1/E2/E3, 미탐 포함 선행량·오탐·표본 수.
- Guard 보류·승인·차단 데모, 비용·실패 사례, 코드·환경·revision·seed와 개인 기여.
- 실측 효과가 확인된 범위만 제품 가설에 반영. 고객 파일럿은 연동·보관·오탐 요구 합의 후.

기획서 v3.0과 동일한 가설·범위·일정을 사용한다. 참고 사건은 연구 동기이며 은닉층 감시의 효과를 증명하는 근거가 아니다.
