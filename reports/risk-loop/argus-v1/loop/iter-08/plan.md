반복 8은 **확인 반복**이다. 새 모델 시도는 없다(누적 시도 수 65개 그대로, 보수적 67). 대상은 반복 7 후보 **T7-a** 하나:
학습 행으로 특징마다 중앙값·IQR을 구해 z = (x − 중앙값)/(IQR/1.349), |z| > 3은 ±3으로 자른 뒤 PCA 32 →
고정 동일 가중 순위 앙상블(H2-1c-L23 점별 + T4-1a 쌍 층 23 max + T4-1b 쌍 층 16 행동 직전, 학습 점수 백분위 평균).

평가 에이전트는 모델 연구 에이전트와 다른 인스턴스다. 평가 코드 `evaluate.py` v4(sha256 `a7c36eafdf994f98b61895be4e4b8d237740d0018422d12febab8deb9df0130d`, 계산 전 확인함)와 연구 코드(`iter06_models.py`, `iter07_models.py`)는 **읽고 불러 쓰기만** 하고 고치지 않는다. validation·test는 보지 않는다(성공 판정 조건 1 = 0.90에 크게 못 미치므로 validation 조회 대상이 아님). 11월 라벨은 **초안**. 평가 행은 `iter01_common.headline_filter` 행(9,278 / 위반 79, 판정 칸 10개 / 위반 52).

평가 에이전트의 스크립트·결과는 `artifacts/risk-loop/argus-v1-loop/iter08/`, 문서는 `reports/.../iter-08/`에만 쓴다.

## 할 일

1. **독립 재계산**: v4 `evaluate()` 전체(nested CV, family bootstrap CI, 섞기 (a)(b) 각 20회, 기준선)로 T7-a를 다시 계산한다. 연구 쪽 수치(판정 지표 0.696, seed 0.693/0.701/0.693, 자기 섞기 (b) 0.523±0.067, (i′) 0.105, (i″) 0.170)와 비교해 0.005 넘게 다르면 표시한다.
2. **안정성**:
   - 같은 모델을 fold seed 0~9 (10개)로 돌린다. 격자가 1개라 nested CV 안쪽 선택이 없으므로 `run_cv`(고정 모델)로 돌리고, seed 0~2 OOF가 1단계 nested 결과와 같은지 확인한다. 판정 지표 분포(평균·SD·최소·최대)와 10-seed family bootstrap CI를 낸다.
   - 비교용으로 전처리 전 모델 T6-2(표준화 → PCA)도 seed 0~9로 돌린다(같은 seed끼리 차이 = 전처리 효과의 seed 분포).
   - 자기 섞기 (b)를 fold seed 0·1·2에서 각 20회 계산한다(seed 0은 평가 코드 값과 같아야 함; 같은 절차의 점수 저장용 재현).
   - (i′) 여유의 표준오차: (가) 계산 절차 잡음 = 판정 지표의 fold seed 잡음(seed 3개 평균) + 자기 섞기 (b) 평균의 표준오차 + 기준값 0.591(H2-1c 섞기 (b) 20회, SD 0.068)의 표준오차. (나) 데이터 잡음 = family 복원 추출 2,000회에서 판정 지표 − max(자기 (b) 평균, 기준 모델 (b) 평균)을 같은 표본으로 함께 다시 계산(짝지은 bootstrap; 기준 모델 섞기 OOF는 반복 4 저장 파일 `iter04/shuf_b_H2-1c.npy`). 정규 근사로 "참 여유 ≥ 0.10"일 확률을 낸다. (i″)(seed 0 − 자기 (b))도 같은 방식.
3. **진단(시도 수에 넣지 않음, 판정에 쓰지 않음)**: 구성 모델 셋(H2-1c-L23, T4-1a, T4-1b)을 각각 혼자, 견고한 전처리 있음/없음으로 fold seed 0~2 판정 지표를 낸다. 싸면 각 섞기 (b) 20회(seed 0)도 낸다. 전처리 효과가 앙상블에서만 나오는지, 구성 모델 하나하나에서도 같은 방향인지 본다.
4. **판정**: `success_gate`(조건 6 감시 감사는 미입력 = 대기), 사전 등록 후보 조건 (i′)(i″)(ii), 감시 R1(0.656 + 0.12 = 0.776), 시도 65개 대비 운 보정. 결과는 `iter-08/eval.md`, `eval.json`.

## 판단 기준 (계산 전에 정함)

- 재계산 일치: 모든 비교 수치 차이 ≤ 0.005.
- "믿을 만한 후보": 사전 등록 조건 (i′)(i″)(ii)를 재계산에서도 넘고, 10-seed 판정 지표 평균으로 계산한 (i′)도 ≥ 0.10이며, 여유가 절차 잡음 SE의 1배 이상이면 "안정 통과", 0~1 SE면 "경계(잡음 안)", 음수면 "재현 실패".
