## 1. 왜 하는가 (진단)
- 모든 도구를 한데 섞어서 잰 AUROC는 0.88–0.92로 높다. rollout 정보만 쓴 모델도 0.596이 나온다.
- 그런데 판정 지표인 "같은 도구 안 AUROC"(같은 도구×출처 칸 안에서만 위반과 정상을 비교)는 0.39–0.72에 그친다.
- 해석: 모든 도구를 섞어 학습한 모델은 "어느 도구·어느 시나리오가 위험한가"를 배운다. 이 신호는 같은 도구 안에서는 쓸모가 없거나 오히려 거꾸로 간다.
- 그래서 학습 방법만 바꿔서, 모델이 **같은 도구 안에서 위반과 정상을 가르는 방향**만 배우게 한다.

## 2. 방법 — "같은 도구 안 학습" (학습 때만 바꿈)
도구 이름·출처는 **학습 fold 안에서만** 쓴다. 칸 평균은 그 적합에 주어진 학습 행으로만 계산한다: 바깥 평가 때는 바깥 학습 fold, 안쪽 조정값 선택 때는 **안쪽 학습 행만**(안쪽 평가 행·바깥 평가 행은 칸 평균에 들어가지 않는다 — 시험으로 확인). 점수를 매길 때는 도구 이름을 입력으로 쓰지 않는다(채점 행의 도구·출처·family·rollout 정보를 섞어도 점수가 똑같아야 한다 — 감사 항목).
"칸" = 도구×출처 한 쌍(평가 지표가 묶는 단위와 같다).

### 방법 1 — 칸별 중심화 (W1)
- 학습 fold 안에서, 늘 하던 전처리(robust 척도 → PCA) 뒤의 특징에서 **각 칸의 학습 행 평균을 뺀다.** 위반·정상을 함께, 칸마다.
- 중심화한 특징으로 모델을 학습한다. 손실은 원래 모델의 손실 그대로다.
- 점수를 매길 때는 학습한 선형 방향을 **중심화하지 않은 원래 특징**에 그대로 곱한다.
- **정확하다는 주장은 선형 점수에만 해당한다.** 선형 모델에서는: w·x = w·(x − μ칸) + w·μ칸 이고, 둘째 항은 칸마다 상수라서 같은 칸 안 AUROC는 이 항을 무시한다(한 fold 모델 안에서 정확. 평가 칸은 바깥 fold 5개의 점수를 모으므로 fold마다 다른 상수가 섞인다 — 원래 모델들도 같은 사정).
- 비선형 모델(CNN-MLP)에서는 학습 때 관측 지점별 PCA 입력을 칸마다 중심화한다. 점수 때는 도구 이름을 쓸 수 없으므로 **학습 fold 전체 평균**으로 중심화한다. 이것은 **근사**다(비선형이라 칸 상수가 빠지지 않는다). 참고로 PCA 입력은 학습 fold 관측 지점 전체 평균이 이미 0이므로 점수 때 중심화는 사실상 그대로다.

### 방법 2 — 칸 안 쌍 학습 (W2)
- 같은 칸 안에서 (위반, 정상) 쌍만 만든다. rollout이 달라도 된다. 같은 rollout·같은 도구 쌍은 가중치 2, 나머지는 1.
- 쌍 가중치는 기존 관례(models.same_group_pairs)처럼 위반 하나의 쌍들이 "칸의 정상 수"로 나뉘고(1/정상 수), 전체 평균이 1이 되게 맞춘다.
- 칸을 넘는 쌍은 없다. 도구를 넘나드는 BCE(점별 손실)도 없다.
- 선형 모델에서는 같은 칸 쌍의 차이가 중심화와 무관하므로, 방법 2는 중심화 여부와 상관없이 같은 해를 준다.

### 방법 3 — 둘 다 (W3)
- 방법 2의 칸 안 쌍 손실 + **중심화한 특징 위의 작은 BCE(가중치 0.1)**. 이 BCE는 점수 크기를 잡아주는 용도다. 비율은 "쌍 손실 평균 : BCE 평균 = 1 : 0.1"(아래 모델별 식).
- 비선형 모델에서는 두 항 모두 중심화한 입력으로 계산한다.

### 쓸 수 있는 학습 위반
학습 fold 안에 같은 칸 정상 행이 하나도 없는 위반은 쌍을 만들지 못한다. 이런 칸은 평가 칸도 아니므로(평가 칸은 위반 3개·정상 3개 이상) 문제가 아니지만, fold마다 **쓸 수 있는 학습 위반 수**(같은 칸에 학습 정상이 1개 이상 있는 위반)를 보고한다. 전체 데이터 기준으로는 76개 중 75개(fetch_certificate_chain|oct 위반 1개는 정상이 0개).

## 3. 적용할 모델 (기반 3개 × 방법 3개 = 9 시도)
누적 시도 수: **160 → 169 (보수 계산 162 → 171)**. 160의 근거: 사이클 1 C 단계 뒤 132(보수 134) + S 단계 구조 7개 × 토글 상태 4개 = 28 → 160(보수 162). 이번 9개를 더해 169(보수 171). §7 진단에서 새 입력 변형이 추가되면 그만큼 더 센다. 조정값(C, weight decay)은 각 기반의 기존 격자 그대로이고, 안쪽 family CV-4로 고르며, 시도 수에 넣지 않는다. 대조군·섞기·원래 모델 재계산은 시도가 아니다.

### 3.1 T7-a (지금까지 최고, 원래 형태 0.721 = 대조군)
- 특징·전처리는 `iter06_models.make_t62` / `iter12_remeasure.py`와 같다: 행마다 풀링한 activation → fold 안 robust 척도 → PCA → 구성원 3개 → 학습 행 점수 기준 백분위의 평균.
  - 구성원 ① 층 23 최댓값, PCA 32, 점별 로지스틱(기존 이름 H2-1c), C 0.1
  - 구성원 ② 층 23 최댓값, PCA 32, 같은 rollout 쌍 학습(기존 이름 T4-1a), C 0.001
  - 구성원 ③ 층 16 행동 직전, PCA 10, 같은 rollout 쌍 학습(기존 이름 T4-1b), C 0.01
- 방법 1: 각 구성원을 칸별 중심화한 PCA 특징으로 원래 손실 그대로 다시 학습(①은 원래 가중치 — 출처×클래스 + 위반 있는 칸 정상 상향 — 그대로, ②③은 같은 rollout 쌍 그대로).
- 방법 2: 세 구성원 모두 칸 안 쌍 로지스틱(절편 없음, 원래 sklearn 쌍 학습과 같은 식 0.5‖w‖² + C·Σ가중치·[쌍 손실 2벌]), 구성원마다 원래 C.
- 방법 3: 0.5‖w‖² + 2C·(Σ_쌍 W·softplus(−w·d) + 0.1·ΣW·BCE평균). BCE는 칸별 중심화 특징, 출처×클래스 가중치, 절편 있음(규제 안 함). 점수에는 절편을 쓰지 않는다.
- 점수: 학습한 방향 w를 중심화하지 않은 특징에 곱함 → 학습 행 점수(역시 중심화 안 함) 기준 백분위 → 세 구성원 평균. 백분위 평균은 선형이 아니므로 "칸 상수가 정확히 빠진다"는 성질은 구성원 하나씩에만 성립한다.
- 조정값 없음(격자 1개) → nested는 단순 교차검증과 같다.

### 3.2 선형 기준 모델 (`obs_models_s0f.py`의 볼록 기준선)
- 층 20 관측 캐시 → 관측 지점마다 fold 안 robust 척도 → ±3 자르기 → PCA 32 → 좌표별 학습 SD로 나눔 → [좌표별 관측 지점 최댓값 32, 행동 직전 지점 32] → 학습 행 평균·SD로 표준화 → 로지스틱. 토글은 모두 끔.
- 원래 목적함수: 0.5‖w‖²/a + 0.2·BCE평균(클래스 균형) + 1·같은 rollout 쌍 평균, a = C·n/0.2, 절편 규제 안 함, L-BFGS.
- 방법 1: 표준화한 64개 특징에서 칸 평균을 빼고 원래 목적함수 그대로.
- 방법 2: 0.5‖w‖²/a + 1·칸 안 쌍 평균(BCE 없음). a는 그대로 C·n/0.2.
- 방법 3: 0.5‖w‖²/a + 1·칸 안 쌍 평균 + 0.1·BCE평균(중심화 특징).
- 점수: 중심화하지 않은 표준화 특징 × w (+ 절편).
- 조정값 C ∈ {0.01, 0.1, 1}, 안쪽 CV-4.

### 3.3 CNN-MLP (`obs_models_s0f.py`, 가장 느려서 마지막)
- 같은 입력(관측 지점별 PCA 32 순서열) → Conv1d 32→8 → ReLU → Conv1d 8→8 → ReLU → [최댓값, 평균, 행동 직전 출력] → 24→16 MLP → 2. Adam lr 3e-3, 200 epoch, 드롭아웃 0.3, init seed 0. 토글은 모두 끔.
- 방법 1: 관측 지점 PCA 입력을 칸마다 중심화(칸 평균 = 그 칸 학습 행의 모든 관측 지점 평균)해서 원래 손실(0.2·BCE + 1·같은 rollout 쌍)로 학습. 점수 때는 학습 fold 전체 관측 지점 평균으로 중심화(근사).
- 방법 2: 중심화 없이, 손실 = 칸 안 쌍 손실만.
- 방법 3: 칸별 중심화 입력, 손실 = 칸 안 쌍 손실 + 0.1·BCE(클래스 균형). 점수 때 전체 평균 중심화(근사).
- 조정값 weight decay ∈ {1e-3, 1e-2, 1e-1}, 안쪽 CV-4.
- 행동 직전 지점만 쓰는 대조군에서는 행동 직전 지점끼리의 칸 평균으로 중심화한다.

## 4. 평가 (S 단계와 같은 절차)
- 바깥: family StratifiedGroupKFold-5(evaluate.make_folds), fold seed 0·1·2. 조정값은 바깥 학습 fold 안의 family CV-4가 고른다(evaluate.nested_cv, inner_splits 4). **nested 값이 공식 숫자**다. CI는 evaluate.metrics의 family 부트스트랩(2,000회, seed 0).
- 라벨 섞기: (a) 출처 안, (b) 출처×family 안, 각 20회, fold seed 0, nested에서 가장 많이 고른 조정값 고정(evaluate.shuffle_test, perm_seed 0).
- 행동 직전만 쓰는 대조군(기반마다, 같은 방법): T7-a는 세 구성원의 표현을 행동 직전 위치로 바꿈(층 23 행동 직전 ×2, 층 16 행동 직전), 선형 기준 모델·CNN-MLP는 행동 직전 지점 하나만. 같은 격자, 같은 안쪽 CV-4.
- 이득: 같은 family 재표본에서 두 모델의 seed 평균 같은 도구 안 AUROC 차이(2,000회, seed 0, evaluate.family_bootstrap_ci와 같은 재표본 방식).
  - ① 원래 기반 모델 대비(같은 모델, 방법 없음, 같은 격자·같은 nested 절차로 다시 계산. CNN-MLP 원래 모델은 S 단계 저장소에 같은 적합이 있으면 읽어 쓰고, 없으면 같은 코드로 계산).
  - ② T7-a 원래 형태 대비(0.721, 같은 절차로 fold seed 0–2 재계산).
- 같이 보고: 기반 안에서 방법 사이 OOF 점수 순위 상관(Spearman, seed마다 계산 후 평균; 거의 1이면 "사실상 같은 모델"로 해석), 전체 AUROC(모든 기반, 특히 CNN-MLP 방법 1·3의 학습·채점 입력 어긋남을 보려고), 출처별 값, 칸별 값, 섞기 평균, 대조군, 쓸 수 있는 학습 위반 수, 운 보정(이전 규칙: 값 − 0.05·E[정규분포 N개 최댓값], N = 169).

## 5. 판정 규칙 (미리 정함)
- **nested 값이 0.90 이상**인 조합이 있으면 맨 앞에 크게 알린다. 그래도 **validation은 열지 않는다**(사용자 결정 대기).
- "개선"이라고 부르려면 셋 다: ① 원래 기반 대비 이득의 95% CI 하한 > 0, ② 섞기 (a) 평균이 0.45–0.55, ③ nested − max(자기 섞기 (b), 0.596) ≥ 0.10.
- T7-a 0.721보다 낫다고 하려면: T7-a 대비 이득의 95% CI 하한 > 0.
- 행동 직전 대조군이 본 모델과 같거나 높으면 "관측 지점 전체를 쓰는 이득 없음"으로 적는다.

## 6. 지키는 것
- train split만. validation·test는 봉인 그대로. evaluate.load가 train 외 split을 거부한다.
- 실행 중인 S 단계 격자가 import하는 파일(evaluate.py, obs_grid.py, obs_models.py, obs_grid_s.py, obs_models_s.py, obs_models_s0f.py)은 **고치지 않는다**. 새 코드는 `within_tool.py`, `test_within_tool.py`에만.
- 누출 감사: 적합마다 (1) 학습·채점 행 겹침 없음, (2) 칸 평균은 학습 행으로만 계산, (3) 모든 쌍이 학습 행 안·같은 칸 안·(위반, 정상), (4) 기반·방법마다 한 번, 채점 행의 도구·출처·family·rollout을 뒤섞어도 점수가 똑같음.
- 합성 데이터 시험(실제 데이터 전): (가) 선형 방법 1에서 중심화 안 한 특징으로 매긴 점수의 칸 안 AUROC = 중심화 특징 점수의 칸 안 AUROC(정확히 같음), (나) 칸 평균이 칸을 넘어서는 위반을 강하게 예측하지만 칸 안 진짜 신호는 다른 방향인 합성 데이터에서, 원래 모델은 실패하고 방법 1·2가 진짜 방향을 되찾음, (다) 방법 없음이 기존 코드(선형 기준 모델, CNN-MLP)와 같은 점수를 냄, (라) 누출 감사.
- 자원: 다른 S 단계 격자가 작업자 2개로 도는 중이고 PC가 느리다. **작업자 1개, 스레드 1–2개.** 남은 RAM이 1 GB 아래면 적합을 멈추고 기다린다. 순서: T7-a → 선형 기준 모델 → (시간이 되면) CNN-MLP. CNN-MLP가 끝나지 않으면 끝난 부분만 "미완"으로 표시해 보고한다.
- 도구 이름이 점수에 어떤 형태로도 들어가지 않음: 점수 함수는 채점 행의 위치만 받고, 칸 정보는 학습 위치에서만 읽는다. 기반 3개 × 방법 4개(방법 없음 포함) 모두, 합성 데이터와 실제 데이터(fold 0) 양쪽에서 채점 행의 도구·출처·family·rollout·라벨 상태를 뒤섞어도 점수가 비트 단위로 같아야 한다. 하나라도 다르면 실행을 멈춘다. CNN-MLP 방법 없음의 이 검사는 S 단계 저장소를 건너뛰고 직접 계산한 점수로 한다.
- 중심화 감사: 칸 평균 계산에 **실제로 쓰인 행 목록**(위치)을 그 적합의 학습 행과 비교하고, 채점 행과 겹치지 않는지 본다(적합마다, 다르면 멈춤). 이와 별도로 구조상 적합 함수는 학습 위치만 받으며, nested 시험으로 안쪽 선택 때 안쪽 학습 행만 쓰이는 것을 확인했다.

## 7. 입력 자르기(clip) 진단 (시도 아님, 본 실행 전에)
의심: 선형 기준 모델의 입력(층 20 캐시 → robust 척도 → ±3 자르기)이 신호를 잃는다. 근거: 그 행동 직전 대조군은 0.396인데, 같은 행동 직전 정보를 쓴 다른 모델(사이클 1의 행동 직전 모델, M0 방향에서 출발하는 필터 모델, 자르기 없음)은 0.594.
- fold seed 0·1·2, 행동 직전 지점만 쓰는 선형 기준 모델(방법 없음, C는 같은 격자 {0.01, 0.1, 1}에서 안쪽 CV-4로 선택)을 세 입력으로 돌린다:
  (a) 지금 그대로(robust 척도 → ±3 자르기 → PCA 32 → SD로 나눔),
  (b) 자르기 없음(robust 척도 → PCA 32 → SD로 나눔),
  (c) 사이클 1 입력(학습 fold 평균만 빼고 → PCA 32 → SD로 나눔, `obs_models.ObsData.embed`).
- 세 값 모두 보고한다. 시도 수에 넣지 않는다.
- 미리 정한 규칙: (b)·(c) 중 seed 0–2 평균이 높은 쪽을 고르고, 그 쪽이 (a)보다 **seed 0–2 평균 차이 ≥ 0.05 이고 동시에** 같은 family 재표본 짝 비교(`paired_gain`, 2,000회)의 95% CI 하한 > 0 이면 "확실히 되찾음"으로 본다. 그러면 그 입력을 선형 기준 모델과 CNN-MLP의 변형으로 추가하고 **"결과를 본 뒤 고른 입력"**이라고 표시한다: 기반마다 방법 없음·W1·W2·W3 4개 = 8개 + 진단에서 두 입력 중 하나를 고른 것 2개 = **시도 10개 추가(169 → 179, 보수 171 → 181)**. 평가 절차(§4)·판정 규칙(§5)은 똑같이 적용하고, 원래 입력 결과도 그대로 보고한다. 조건을 못 넘으면 변형 없이 원래 입력만 쓰고 시도는 169 그대로다(진단은 시도 아님).
