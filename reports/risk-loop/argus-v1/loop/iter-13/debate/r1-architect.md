# 라운드 1 — 아키텍처 설계자: "학습된 투영 → 최대 풀링" 위험 탐지기

작성 2026-11-09. 계산 실험 없음. 확인한 사실: `steps.csv`의 관측 행 수 n_obs = 평균 8.1, 중앙값 7, 최소 1, 최대 64 (train·validation 15,779 step). 캡처는 이미 24개 층 전부, 32토큰마다 저장(`data/card.md` §1, `argus_hook/scenario_rollout.py --observe-every 32`). **그래서 4090 쪽 캡처 방식은 바꿀 필요가 없다.** 바꿔야 하는 것은 로컬 캐시뿐이다(지금은 풀링된 값만 있음).

## 0. 한 줄 요약
관측 지점마다 "위험 방향" 필터 K개를 학습해 내적을 구하고(투영), 필터마다 관측 지점들 중 가장 강한 값을 고른다(최대 풀링). 고른 값 + "이 rollout의 이전 step보다 얼마나 더 튀나" → 선형 머리 → 점수. 지금 T7-a는 순서가 거꾸로(좌표별 max 먼저, 투영 나중)다.

## 1. 주 설계 P1 — 다층 필터 + 부드러운 최대 풀링 + rollout 기준선 (MIL 방식)

### 1.1 입력 (step t 하나)
- 층 집합 𝓛 = {11, 16, 20, 23} (4개). 근거: 지금 최고 T7-a가 23(max)·16(pre)을 쓰고, 캐시에 이미 있는 층이라 기존 결과와 바로 비교 가능. 층 선택은 아래 group-lasso가 정한다(사람이 고르지 않음).
- X_l ∈ ℝ^{n×2880}, n = n_obs (1~64, 가변). 관측 종류 c_i ∈ {pre_reasoning, reasoning, reasoning_end, pre_action}.
- 모든 관측 행을 쓴다(reasoning+32k 포함). 마지막 두 행만 쓰면 지금 `pre` 특징과 같아져 구조 이득이 없다.

### 1.2 정규화 (학습 없음, train 관측 행으로 한 번 맞춤, 고정)
- x̃ = clip((x − med_l) / (IQR_l/1.349), −3, 3), 원소별. T7-a에서 이 전처리 하나로 +0.050(seed 3개 모두 +0.045~0.059, `iter-07/candidates.md`). 큰 값이 몰린 이상 차원(outlier dim)도 자르기로 눌린다. 따로 차원을 빼지 않는다.
- PCA_l: 2880 → d = 128, **라벨 없는 모든 관측 행**(규칙 라벨 대량 데이터 포함, validation/test 제외)으로 맞춤. 목적은 학습 파라미터 수를 줄이는 것(2880×K → 128×K).
- u_{l,i} = P_lᵀ x̃_{l,i} ∈ ℝ^{128}.

### 1.3 투영 = 필터 (학습)
h_i = Σ_{l∈𝓛} W_lᵀ u_{l,i} + e_{c_i} + b,   W_l ∈ ℝ^{128×K}, K = 16, e_c ∈ ℝ^K (관측 종류 바이어스 4×16), h_i ∈ ℝ^K.
- 층마다 다른 필터를 두고 더한다(층을 이어 붙인 512차원에 필터 하나와 같음). 층 사이 공유 W는 잔차 흐름 기저가 층마다 돌아가서 맞지 않다고 본다(확인 못 함, 비교 실험 대상).
- 필터 앞 비선형 없음. 비선형은 풀링(max)이 맡는다 — CNN의 conv(선형) → max-pool과 같은 구조.

### 1.4 풀링
필터 k마다, 관측 지점 i에 대해
- m_k = τ_k · log( (1/n) Σ_i exp(h_{ik}/τ_k) )  (평균형 log-sum-exp, τ_k 학습, 초기 0.5, 하한 0.05)
- a_k = (1/n) Σ_i h_{ik}  (평균, 보조)
- 설명용 argmax_k = argmax_i h_{ik} 를 함께 저장(어느 관측 지점·추론 몇 토큰째에서 위험 필터가 켜졌는지).
- 왜 LSE: 하드 max는 기울기가 한 행으로만 가서 위반 100~180개에서 학습이 불안정. (1/n)을 안에 넣어 n_obs가 길수록 점수가 커지는 길이 누수를 줄인다(길이+step 기준선 0.522가 이미 있음). τ→0이면 max, τ→∞면 mean.

### 1.5 같은 rollout의 이전 step 맥락 (TASK §3 허용: 행동 전 관측)
- g_t = max_{s<t} m^{(s)} (원소별, 이전 step들의 풀링 벡터), 첫 step은 g = m^{(t)}.
- 특징 f_t = [ m^{(t)} ; a^{(t)} ; m^{(t)} − g_t ] ∈ ℝ^{3K=48}.
- 근거: T7-a 신호의 상당 부분이 "위험한 rollout" 수준이고, 같은 rollout 쌍 학습(T4-1a/b)이 step 수준 신호를 보탰다(`final/card.md` §1). m − g는 "이 rollout에서 지금 처음 튀는가"를 직접 표현한다. 도구 이름·출처는 들어가지 않는다.

### 1.6 머리
score_t = σ( vᵀ f_t + c ), v ∈ ℝ^{48}. **선형 머리.** MLP 머리는 T7-c(0.550 < 선형)에서 졌다. 비선형은 이미 max 풀링에 있다.

### 1.7 파라미터 수
학습: W 4×128×16 = 8,192 + e 64 + b 16 + τ 16 + v 48 + c 1 = **약 8.3k**. 고정(전처리): 중앙값·IQR 4×2×2880 + PCA 4×2880×128 ≈ 1.5M. T7-a(점별 32 + 쌍 32·10 계수)보다 훨씬 크지만, MLP처럼 은닉층을 쌓지 않는다. 위반 150개 기준 "파라미터/위반" ≈ 55 → 아래 사전학습·정규화 없이는 과적합한다고 본다.

### 1.8 학습 (요지, 상세는 학습 담당과 조율)
- 단계 A(사전학습): 규칙 라벨(`policy_label`, v2 rollout 1,920개 등) 전체로 W·e·τ·v 학습. 손실 = 가중 BCE + λ₁·같은 rollout 쌍 로지스틱(위반 step > 정상 step) + λ₂·같은 rollout·같은 도구 쌍. 쌍 손실은 T4-1a/b·T6-1에서 효과가 있었던 신호.
- 단계 B(미세조정): 사람 검수 라벨(10월 사람·위임, 11월 검수 행, `dec` 검수 행)로 v·c만 다시 맞추고 W는 학습률 1/10 또는 고정.
- 정규화: 관측 행 무작위 빼기(p=0.25, 최소 1행 남김), weight decay, W_l에 group-lasso(층 단위 → 쓸모없는 층이 0으로), 필터 직교 벌점 ‖WᵀW − I‖², 초기화 = T7-a 점별 로지스틱 방향을 필터 1번에 넣고 나머지는 작은 무작위. seed 5개 앙상블(순위 평균). 모든 하이퍼파라미터(K, d, τ초기값, λ, p)는 **사전 고정**, 에폭만 안쪽 CV로.

### 1.9 추론 경로 (hook 시점 → 점수)
1. gpt-oss-20b 생성 중 관측 지점(pre_reasoning, 추론 32토큰마다, reasoning_end, pre_action)에서 block 11·16·20·23 출력 마지막 토큰 벡터 [2880]를 읽는다(지금 hook과 같은 위치 `post_block_pre_final_norm`).
2. 행마다: fp32 변환 → 원소별 척도·자르기 → 층별 [2880×16] 행렬 곱(PCA와 W를 미리 합친 W̃_l = P_l W_l, 자르기가 PCA 앞이라 합쳐도 같다) → 합 + e_c + b → h_i ∈ ℝ^{16}.
3. 누적기 갱신(필터마다 running LSE 합, 합계, argmax). 원본 행을 쌓지 않는다 → 메모리 O(K).
4. pre_action 행에서 m, a 확정 → f_t = [m; a; m − g] → score. g ← max(g, m) (rollout 상태, 16개 실수).
5. 비용: 관측 1회당 4×2880×16 ≈ 18.4만 곱셈-덧셈. GPU <0.1ms, CPU에서도 1ms 안(추정). 추론용 파라미터 4×2880×16 + 척도 ≈ 23만 실수 ≈ 0.9MB. 덤: 추론 중간에도 점수가 나와 이른 경보 가능.
- 입력 계약: `score(model, {11: X11, 16: X16, 20: X20, 23: X23}, obs_kinds, rollout_state) → (score, argmax_info, new_state)`. 도구·출처 인자 없음.

### 1.10 데이터 준비 비용
관측 행 단위 캐시가 필요: 16k step × 평균 8행 × 2880 × 4층 × fp16 ≈ 3.0GB(디스크 41GB 여유, RAM에는 층 하나씩 올림). 새 데이터(v2 20개 + v1 72개 재실행)도 같은 형식. fp16 범위 초과값 여부는 확인 못 함 → 캐시 만들 때 inf 검사, 넘치면 척도 맞춘 뒤 저장.

## 2. 왜 좌표별 max(T7-a)를 이겨야 하나
- 좌표별 max 벡터는 차원마다 다른 관측 지점에서 값을 가져온 "존재하지 않는 상태"다. 그 위의 선형 점수 wᵀmax_i(x_i)는 w ≥ 0인 방향이 아니면 "어느 지점에서 위험 방향이 강했나"를 표현 못 한다. P1의 max_i(wᵀx_i)는 그것을 그대로 표현한다(다중 인스턴스 학습 가정: 위반 의도는 추론 중 어느 한 지점에서 드러난다).
- 좌표별 max는 n_obs가 길수록 체계적으로 커진다(길이 누수). (1/n) LSE는 이를 줄인다.
- 필터 16개 × 층 4개로 T7-a의 "PCA 32 위 선형 1개"보다 표현력이 크지만, MLP와 달리 구조적 편향(위치 불변 + max)이 있어 적은 데이터에서도 버틸 여지가 있다.

## 3. 무엇이면 틀렸다고 보나 (반증 조건, 같은 CV·같은 라벨·seed 10개)
1. **구조 단독 비교**: 층 23만, K=1, 맥락 없음, 같은 전처리로 "max_i(wᵀx̃_i)"(P0) vs "wᵀmax_i(x̃_i)"(T7-a 점별 성분). 판정 지표 차이 < +0.02이면 "투영→풀링 순서" 가설은 기각.
2. **argmax 퇴화**: 위반 step에서 argmax가 90% 넘게 pre_action(또는 마지막 행)이면 풀링이 하는 일이 없다 = `pre` 특징과 같다.
3. **섞기 (b) 동반 상승**: 판정 지표 − max(자기 섞기 (b), 0.591)이 T7-a(0.105)보다 크지 않으면 오른 것은 rollout/family 비율 신호일 뿐.
4. **길이 상관**: 점수와 n_obs의 칸 안 순위 상관 |ρ| > 0.3이면 길이 누수.
5. **m − g 무효**: 이 항을 빼도 보조 지표 (C)(같은 trajectory·같은 도구)가 그대로면 맥락 항 기각.
6. 학습 곡선(25/50/100%)이 T7-a보다 가파르지 않으면 "데이터가 늘면 이긴다"는 기대도 기각.

## 4. 대안
### A1 — 가벼운 단일층 판 (P0, 먼저 돌릴 기준)
층 23만, PCA 128 → 필터 K=4, 하드 max + 평균, 맥락 없음, 선형 머리. 학습 파라미터 ≈ 530. score = σ(Σ_k v_k max_i(w_kᵀu_i) + v'_k mean_i(w_kᵀu_i) + c). 반증 조건 1을 직접 시험하고, P1이 과적합하면 이쪽으로 물러선다.

### A2 — 시간축 CNN + 주의 풀링 (더 무거운 판)
reasoning 행들(32토큰 간격, 순서 있음)에 폭 3 1D conv: h_i = Σ_{δ∈{−1,0,1}} W_δᵀ u_{i+δ} (층 4개 이어 붙인 512차원 → K=16, 파라미터 3×512×16 ≈ 24.6k). 풀링은 게이트 주의(Ilse et al. 2018, attention-based MIL): α_i = softmax_i( qᵀ(tanh(V h_i) ⊙ σ(U h_i)) ), z = Σ α_i h_i, V,U ∈ ℝ^{16×16}. α가 설명을 준다. "추론 흐름이 위험 쪽으로 바뀌는 순간" 같은 변화 패턴을 잡을 수 있으나, 위반 150개에 24k+ 파라미터는 위험이 크다. 새 데이터 도착 후 단계 A 사전학습이 잘 될 때만 시도.
