# 토론 결과 요약 — "학습된 투영 → 최대 풀링" (2026-11-09)

참가: 아키텍처 설계자, 데이터·학습 전략가, 평가·검증 담당, 시스템·추론 엔지니어, 망나니. 4라운드(입장 → 비판 → 반박 → 최종 판정). 원문: 같은 폴더 `r1-*`, `r2-executioner.md`, `r3-*`, `r4-executioner-final.md`(최종 설계의 기준 문서).

## 최종 설계 (사전 등록 대상)
- 입력: 행동 전 관측 지점별 은닉 상태, 32토큰 간격 기준(8토큰 새 데이터는 32로 솎음).
- 캐시: 층 16·20·23을 라벨 없이 맞춘 PCA-512로 투영해 저장(약 2.6GB, TASK 3GB 이내, 원본 텐서 저장 없음). 기저는 기존 train 행으로만 맞추고 dec 전에 해시 고정.
- M0(고정 필터): 층 20 행동 직전 행으로 배운 방향 1개 → max·mean·행동 직전 값 → 작은 선형 판단층.
- **M1′(주 모델)**: 층 20 → fold 안 PCA 32 → 학습된 필터 4개(32×4, 지점마다 같은 필터 = CNN의 합성곱) → 필터별 max·mean·행동 직전 값(12개) → 선형 판단층. 학습 파라미터 141개. 손실 = 같은 rollout 쌍 손실 + 0.2×행동별 손실 + 시작점으로 당기는 벌점. 조율은 벌점 세기 β ∈ {0.1, 1, 10} 하나만, 200 epoch 고정, 초기값 seed 3개 평균.
- 세 번째 시도(순서 고정): 길이 검사(K3)에 걸리면 top-2 평균 풀링, 아니면 M2(층 20+23, 281개). 시도 상한 3(누적 68 → 71).
- 대조군: 같은 필터를 행동 직전 행에만, 좌표별 max 선형, T7-a, rollout만 보는 모델. fold seed 10 × 초기 seed 3, 라벨 섞기 (a)/(b) 각 20회, 지점 순서 섞기·행동 직전 제거 검사.
- 중단 기준 K1~K11(`r4-executioner-final.md`). 핵심: K1 "M1′ − 행동 직전만 모델"의 신뢰구간 하한 ≤ 0이면 풀링은 장식 → 중단. K7 dec 확인은 1회. K11 캐시 결과가 원본 특징 결과와 0.01 이내.
- 추론 패키지 `ArgusScorer`(후보 아님 표시): hook 텐서를 한꺼번에/생성 중 스트리밍으로 받아 점수·백분위·차단/통과 판단·가장 강하게 반응한 지점과 그 앞 32토큰 추론 문장을 출력. 일치 기준: 캐시 입력 ≤1e-5, HF 원본 입력 ≤1e-3, 문턱 근처 밖 판단 동일.

## 순서
- 지금(기존 데이터): 1 사전 등록 고정 → 2 build_features 패치(observe_every·솎기) + 평가 v5 → 3 4090용 시험 실행 점검 스크립트 → 4 PCA-512 캐시 → 5 ArgusScorer + 데모 → 6 M0/M1′ 실험 → 7 잠금·패키지.
- 4090 데이터 뒤: 8 시험 실행 점검 → 9 dec를 캐시에 추가 → 10 전수/무작위 사람 검수 → 11 dec 확인 1회 → 12 생성 중 값과 재계산 값 비교(≥200 step).
