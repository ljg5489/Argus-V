# 라운드 3 — 데이터·학습 전략가: 인정할 것, 반박할 것, 고친 학습법

작성 2026-11-09. 계산 실험 없음. 캡처는 사용자 결정(`--observe-every 8 --layers all`)으로 확정. 이름: T7-a = 지금 최고 모델(층 23 좌표별 max·층 16 행동 직전 → PCA 32 → 선형 3개 순위 평균). M0·M1 = `r2-executioner.md` §4의 고정 필터·학습 필터 설계.

## 1. 망나니 질문(§5)에 대한 답

**(1) "L2-SP라서 최악 ≈ T7-a" — 철회한다.**
- T7-a의 점별 방향과 쌍 a 방향은 "관측 행들의 좌표별 max 벡터"의 PCA 공간에서 배운 것이다.
- 이 w를 행마다 대고 max를 취한 max_i(wᵀx_i)는 wᵀ(max_i x_i)와 다른 모델이다. 그래서 β→∞이 돌아가는 곳은 T7-a가 아니라 검증 안 된 모델이다.
- 행에 맞는 초기화는 모두 **fold 안에서, 행 단위로** 배운다(층 20, PCA 32).
  - w₁ = M0 방향: 행동 직전 행으로 배운 같은 rollout 쌍 로지스틱. T4-1b와 같은 종류이고, 행 하나에 의미가 있는 것으로 검증된 유일한 방향이다.
  - w₂ = 순진한 MIL 방향: 모든 관측 행이 step 라벨을 물려받는다고 보고, 같은 rollout 쌍 로지스틱을 행끼리 학습한다. 추론 끝 행은 뺀다(다음 도구 정보).
  - w₃·w₄ = 같은 rollout 안 (위반 행 − 정상 행) 차이 벡터의 PCA 1·2번 방향 중 w₁·w₂와 직교하는 성분. 라벨은 쓰지만 손실 최적화는 없다.
- 그래서 "최악"의 기준점은 **M0**(w₁ 고정 + [max, mean, pre_action] 선형 머리)이다. β가 크게 골라지면 M1은 M0 근처로 간다. T7-a와는 반드시 따로 비교한다(K5).

**(2) 능동 선택 행과 판정 행 — 지적을 인정한다. 이렇게 분리한다.**
- 검수 행마다 `review_selection ∈ {census, random, active}` 열을 둔다. 평가 v5 판정 칸은 census·random만 읽는다.
- census = 판정 칸이 될 도구(T1~T4 계약 도구, `iter-12/data_plan.md` §3)의 train 행 **전수 검수**다. 칸당 위반 수십 개·정상 약 15개 이상이라 전수가 가능하다.
- active = 모델 점수로 고른 행이다. 칸 밖 도구, 11월 초안 비판정 행, 보고 내용 행에서만 고르고 **학습 전용**으로 쓴다. 칸 안 행은 이미 census에 들어가므로 active가 판정 집합을 고를 수 없다.
- 선택 순서는 데이터 도착 전에 사전 등록한다(census 먼저, active는 그다음).

**(3) max 뒤의 LEACE — 지적을 인정하고 M1에서 뺀다.**
- LEACE는 선형 분류기만 막는다. 출처 3개와 도구 432종 상황에서 5방향 지우기로는 효과도 실패도 판정하기 어렵다.
- 대신 막는 법: 칸(도구×출처) 안 쌍 손실 위주로 학습하고, 점별 BCE는 0.2로 줄인다.
- 확인 방법(보고만): fold 안에서 8개 풀링 특징 h로 출처를 맞히는 로지스틱의 OOF AUROC를 잰다. 같은 일을 좌표별 max 선형 특징으로 할 때보다 높으면 경고한다. 기준을 넘지 않으면 지우기 시도 자체를 하지 않는다.

**(4) 쌍둥이 D/X 수율 — λ_twin 최대는 철회한다.**
- 새 v2 train 시나리오는 12개(240/20)다. 시나리오마다 X 조건(pilotX 2 + cell5 2) rollout이 4개다.
- train 위반은 수율 0.11~0.30에서 26~72개다(data_plan §3.3 표). X 정당 호출이 rollout당 0.5~1개라면, 서로 다른 위반을 쓰는 쌍둥이 쌍은 약 **20~50개**다. 낮은 수율이면 시나리오당 2개쯤이다.
- 지금 같은 rollout 쌍(약 300개)보다 훨씬 적다. 그래서 쌍둥이는 "같은 칸·다른 rollout 쌍"의 한 종류로 쌍 손실에 넣고 가중치 1(다른 쌍과 같게)을 준다. 따로 쓰는 곳은 평가 보조 지표(쌍둥이 쌍 AUROC)뿐이다.
- "필드를 읽었다"와 "의도"가 섞인다는 지적도 맞다. 이는 X 정상끼리, D 정상끼리의 거리와 비교하는 진단으로만 본다.

**(5) 사전 고정 값.** §3의 표다. 안쪽 CV로 고르는 것은 β(3값)와 epoch뿐이다.

## 2. 규칙 라벨 사전학습 — 인정한다, M1에서 뺀다
- v2 1,920개는 이미 T7-a가 학습한 11월 train 그 자체다. 행동 위반은 25개뿐이다(data_plan §2.1). 그 데이터의 새 정보는 `submit_result` 보고 내용 위반(train 11월 위반 383개 중 359개, TASK.md:39)뿐이다.
- 그래서 M1은 사전학습 없이 학습한다. 11월 초안 행은 지금처럼 학습 행으로 그대로 쓴다. iter-11 D1(c)에서 빼면 10월 칸이 0.697 → 0.641로 떨어졌기 때문이다.
- 보고 내용 보조 과제는 무거운 변형(§5)의 1시도로 미룬다.

## 3. 고친 학습법 — M1 (층 20, PCA 32 fold 안, K=4, 하드 max + 평균, 선형 머리)

| 항목 | 값 (사전 고정) |
|---|---|
| 입력 | 층 20 관측 행, 32 격자만(`dec`도 솎음, §4). 견고 척도는 라벨 없는 PCA 512 투영 캐시(망나니 R3 b)로, 512 기저는 32 격자 행으로만 맞춘다. 그 위에서 PCA 32를 fold 안에서 맞춘다 |
| 모델 | u_ik = w_kᵀz_i + b_k → h = [max_i u_ik, mean_i u_ik]_{k=1..4} (8개) → s = vᵀh + c. 파라미터 4·32 + 4 + 8 + 1 = **141개** |
| 초기화 | w₁~w₄는 §1(1). v는 0, b는 0 |
| 손실 | L = L_pair + 0.2·L_pt + β‖W − W₀‖² + 0.01‖v‖² |
| L_pair | 같은 rollout (위반, 정상) step 쌍에 log(1+e^{−(s_i−s_j)}). 같은 도구 쌍 가중치 1.0, 다른 도구 쌍 0.3(다음 도구 지름길 완화). 같은 칸·다른 rollout 쌍(쌍둥이 포함) 1.0. 위반 하나가 가진 쌍 가중치의 합을 1로 정규화해서, 정상이 많은 rollout이 지배하지 않게 한다 |
| L_pt | 점별 BCE, 출처×클래스 가중치(H2-1c와 같다). 양성 복제는 하지 않는다 |
| β | 안쪽 family 3-fold로 {0.1, 1, 10} 중 선택 |
| 증강 | 관측 행 dropout 0.25(최소 1행은 남김, pre_action도 빠질 수 있음). 잡음은 넣지 않는다(손잡이 줄이기) |
| 최적화 | Adam lr 1e-2, 전체 배치. 최대 300 epoch, epoch 수는 안쪽 CV 평균 곡선 최대점. 초기화 seed 3개의 점수 평균을 "모델 1개"로 본다(평가 담당 §3) |
| 입력 금지 | 관측 종류·도구·출처·step 번호·τ. 필터별 argmax 종류는 기록만 한다(K2) |

- **과적합 수치**: 파라미터 141 > 판정 위반 52(train 79)라서 β가 없으면 학습 데이터 완전 분리가 거의 확실하다. 실효 자유도를 약 10~20으로 묶는 β가 골라질 것으로 예상한다.
- **예측**: 지금 데이터에서는 β=10이 골라져 M1 ≈ M0이 될 가능성이 높다. 차이(K1·K5)는 새 데이터 뒤에야 볼 수 있다. 위반 150개면 지표 SD 약 0.018(data_plan §3.3)이라 +0.04 정도의 차이를 구분할 수 있다.
- **학습 곡선(K6)**: 25/50/100% family로 M1·M0·T7-a를 같이 잰다. M1의 기울기가 T7-a(2배당 +0.06)보다 가파르지 않으면 "데이터 늘면 이긴다" 주장을 하지 않는다.

## 4. 8토큰 대 32토큰 밀도 섞임 문제 (학습 쪽 대책)
- 신호 없는 필터라도 max의 기댓값은 행 수에 따라 커진다. 표준정규 n개의 max 기댓값은 n=8에서 1.42σ, n=25에서 1.97σ다(망나니 R1). 이 +0.55σ가 출처 `dec`와 함께 움직이면 학습이 이것을 출처 지름길로 쓴다.
- mean도 오염된다. 8 격자에서는 추론 중간 행 비율이 커지므로(pre_action·추론 끝이 2/8 → 2/25), mean이 추론 중간 쪽으로 기운다.
- 대책:
  - (a) 출처를 섞는 모든 학습·평가에서 `dec`를 32 격자로 솎는다(위치 j=4k+3, 망나니 §1 나).
  - (b) 512 기저와 fold 안 PCA 32도 솎은 행으로만 맞춘다.
  - (c) 솎아도 추론 길이 차이로 n_obs는 여전히 달라진다. 그래서 K3(칸 안 |Spearman(점수, n_obs)| > 0.3)를 보고 의무로 둔다. 걸리면 dropout을 0.5로 올린 변형을 1회만 시도한다.
- 8 격자 전체는 `dec` 안에서만, 출처 하나로 학습·평가하는 탐색 분석에 쓰고 시도 수에 센다. 여기서 "추론 중간 행이 신호를 더하나"(평가 담당 대조 (d) pre_action 제거)를 본다. 증거가 나오기 전에는 32 격자가 주 설정이다.

## 5. 무거운 변형이 필요로 하는 것 (그 전에는 하지 않는다)
- **선행 조건**:
  - (i) 판정 칸의 사람 검수(census) 위반 ≥ 200개, 칸마다 시나리오 ≥ 3개.
  - (ii) M1이 K1(pre_action만 쓰는 선형보다 CI 하한 > 0)과 K2를 통과.
  - (iii) K6에서 M1의 기울기가 T7-a보다 가파름.
- **무엇을 더하나**(각각 1시도, 한 번에 하나):
  - K=8
  - 층 16+20
  - 보고 내용 보조 머리(`submit_result` 안에서만 위반 대 정상, 필터 공유·머리 분리). 사전 확인으로, 보조 과제만 학습한 모델의 판정 지표가 0.55 이상인지 본다.
  - 8 격자 `dec`
  - PCA 공간 가우스 잡음 0.1
- **규모**: K=8 × 2층은 약 530 파라미터다. 위반 1개당 파라미터 10개 이하라는 경험 규칙이면 실효 자유도 약 50, 즉 위반 약 500개가 필요하다. L2-SP 덕분에 200~300개로도 버틸 수 있다는 것은 추정이고 확인 못 함이다.
- T7-c(MLP, 위반 79개, 0.550)의 실패를 보면, 은닉층을 넣는 변형은 이 조건을 다 채워도 마지막 순서다.
