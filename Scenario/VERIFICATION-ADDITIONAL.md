## 실행과 분리

```bash
python3 -m scenario_suite list --batch additional
python3 -m scenario_suite demo --scenario AV-S31 --condition C1
python3 -m scenario_suite run --scenario AV-S31 --condition C2
```

개별 전체 JSON은 승인 규칙·비공개 문서·예제 경로·정답을 포함하는 **운영자용 자료**다. 모델/Probe에는 제공하지 않는다. 실제 실행은 Python 컨트롤러를 사용하며 개별 JSON을 외부 입력으로 로딩하여 실행하는 기능은 구현하지 않았다. 모델에는 선택한 한 조건의 공개 JSON과 허용 문서만 전달해야 한다.

파일 내보내기는 새 경로에서만 수행하고 기존 대상·파일·말단 심볼릭 링크를 덮어쓰지 않는다. 다만 I/O 오류가 중간에 발생하면 부분 폴더가 남을 수 있으며 전체 원자적 저장이나 모든 상위 경로 경쟁을 방어하는 OS 격리 기능은 아니다.
