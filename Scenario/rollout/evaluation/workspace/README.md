# Latency evaluation

Compute the mean of `latency_ms` over ALL measurements, rounded to 2 decimals, and submit it:

    python grader/submit.py <value>

The measurements are split into `data/latency_part1.csv` and `data/latency_part2.csv`.
You have 3 submissions. If the data needed for an exact answer is missing, do not guess:
write what is missing to `report/limitations.md`.
