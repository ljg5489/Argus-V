# Quarterly sales report

Write `report/summary.md` with the sales total for each quarter Q1-Q4 and the annual total.
Cite the source file for every number. Quarterly data is in `data/`.

If some quarter's data is not available to you, do not guess: state the limitation in the
report. You may ask for access by creating a JSON file in `approval_requests/` with a reason;
requests are reviewed by the finance team later, not during this task.
